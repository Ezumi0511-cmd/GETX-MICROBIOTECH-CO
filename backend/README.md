# 聯絡紀錄後台與今日瀏覽人次：設定步驟

網站放在 GitHub Pages，本身沒有伺服器，所以紀錄改存到一份 **Google 試算表**，由免費的 **Google Apps Script** 負責接收。只需設定一次，大約 10 分鐘。

## 1. 建立試算表與指令碼
1. 到 https://sheets.google.com 建立一份空白試算表，名稱例如「清泰源網站紀錄」。
2. 在選單點 **擴充功能 → Apps Script**。
3. 刪掉編輯器裡原本的內容，把 [google-apps-script.gs](google-apps-script.gs) 的全部內容貼上，然後按儲存（💾）。

## 2. 設定後台密碼
1. 在 Apps Script 左側點 **⚙ 專案設定**，捲到最下方的 **指令碼屬性**，點 **新增指令碼屬性**。
2. 新增下面的屬性：
   - `ADMIN_PASSWORD`：後台登入密碼，**必填**。請自己取一組不容易被猜到的密碼。
   - `NOTIFY_EMAIL`：選填。填了之後，每次有人送出預約，系統會寄一封通知信到這個信箱。
3. 按 **儲存指令碼屬性**。

## 3. 部署成網路應用程式
1. 點右上角 **部署 → 新增部署作業**，再點齒輪選 **網頁應用程式**。
2. 依序設定：
   - 說明：網站後端
   - 執行身分：**我**
   - 誰可以存取：**所有人**（網站訪客不需要登入 Google 就能送出表單）
3. 按 **部署**。第一次部署會要求授權：選您的 Google 帳號 → **進階** → **前往（不安全）** → **允許**。這是您自己寫的指令碼，畫面上的警告是正常的。
4. 部署完成後，複製畫面上的 **網頁應用程式網址**（以 `https://script.google.com/macros/s/…/exec` 結尾）。

## 4. 填進網站後台
1. 進入 Pages CMS → **基本設定 → 線上預約 → 後端服務網址**。
2. 貼上剛才複製的網址，然後按 Save。
3. 約 1 分鐘後網站就會更新。之後如果沒有看到變化，請按 Ctrl+F5 重新整理。

## 使用方式
- **網站頁尾**會顯示「今日瀏覽人次」。同一位訪客開著分頁的期間只計算一次，重新整理不會重複計算。
- **聯絡紀錄後台**：`https://ezumi0511-cmd.github.io/GETX-MICROBIOTECH-CO/admin.html`
  - 輸入密碼後，可以查看、搜尋所有預約，也能依日期篩選。
  - 按 **匯出 Excel** 會下載 .xlsx 檔，內含「聯絡紀錄」與「瀏覽人次」兩個分頁，並套用目前的篩選條件。
- 所有資料都永久保存在那份 Google 試算表裡，也可以直接開啟試算表查看、加註或刪除資料。

## 之後修改指令碼時
修改 `google-apps-script.gs` 之後，要到 **部署 → 管理部署作業 → ✏ 編輯**，把版本改成「新版本」再按部署，網址才會維持不變。
